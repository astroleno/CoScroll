# CoScroll 完整模型预计算与公网复测（2026-10-21）

本轮按用户确认的完整几何预计算方案实现。确定收益为移走默认模型的现场几何处理、减少加载与换模型长任务；持续渲染帧率尚无稳定提升，不能宣称手机已经稳定流畅或达到 60 FPS。

## 实现与等价性

- 原 OBJ 解析后的顶点合并、法线及外层算法提取到共享 `modelGeometry.ts`，计算顺序和默认值不变。
- 离线生成全部 26 个 OBJ 的完整基础/默认外层几何。位置、法线、索引及存在时的 UV 使用原始类型与完整字节，经可逆字节预测、字节平面和 gzip 压缩；不减面、不量化。
- `ModelPreloader` 只对当前发布中完整 URL 匹配的模型使用预计算数据。校验大小、SHA-256、源文件身份、生成版本和参数后，异步解压并填充两层缓存，再完成 `loadModel`。
- `loadModel/getOffsetGeometry`、配置和组件接口不变。自定义模型、非默认几何参数、数据缺失/损坏/超时或缺少原生解压能力时使用原算法。原 OBJ 保留；首访仍只加载当前与下一个模型。
- `models:prepare` 生成数据，`models:check` 和发布前置检查拒绝过期的来源、生成器、依赖锁文件或产物集合。

数据生成身份为 `35923ea9481def4a62db95793222bdc38919a02237cf3c2dba1e84f52e8cdf4c`。

`b3d6e54e6f5aafc1bc3698c9212d51f1f7796452afdd9d74c3c4ffde2c78cc2c`。
全部 26 个基础几何、26 个默认外层和 26 个非默认参数结果的属性/索引字节及元数据对照通过；
同时覆盖负零、Float64 UV、类型、边界、分组、损坏输入、并发加载、缓存复用和回退。

完整预计算文件共 24,461,768 字节。最初未压缩原型为 38,926,280 字节，最终减少约 37.2%。
这不是将原模型减小到原先的 62.8%；预计算包含两层，原 OBJ 另行保留。
以空/观为例，完整数据各为 748,740 / 875,448 字节，原 OBJ 各为 1,146,321 / 1,250,148 字节。
HTTP 再压缩后的大小另有差异，不能把本地未启用 HTTP gzip 的网络结果直接推算为公网收益。

两画布、DPR、丝绸 shader、玉石双层材质与纹理、完整字体、音频和所有手势保持。

本地背景逐像素一致，三个玉石角度（0、π/2、π）至少 99.998% 像素一致，最大通道差 8/255。

## 本地性能与限制

ego-lite Chromium / Apple M4，390×844、DPR 2、Android UA、焦点模拟、浏览器缓存禁用。
压力条件为 4 倍 CPU、4 Mbps 下载、1 Mbps 上传、80 ms 延迟。采样期间未并发本任务构建或下载校验。
未清空系统字体、GPU、V8 或 CDN 缓存；共享机器负载与浏览器/GPU 状态仍会波动。
所有结果均为桌面模拟手机，未进行 Android/iOS 真机测试。
