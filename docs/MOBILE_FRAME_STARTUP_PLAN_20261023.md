## 已有设计范围内的实施

1. `layout.tsx`：同一段首屏准备脚本以内嵌 data URL 的异步经典脚本执行，绕过前置样式表对同步脚本的等待；不增加网络脚本请求。模型立即预载，低优先级贴图提示在小字体完成后启动，不再等待 `window.load`。字体、完整模型和音频检查保持原逻辑及失败回退。
2. `UnifiedLyricsAndModel / JadeModelLoader`：切曲继续复用同一 Canvas 的纹理、环境映射和已编译材质；仅重置旋转/模型子树，使原来的切曲旋转起点保留。内部增加可选旋转修订标记，不变更项目配置或音频/seek 接口。环境强度更新只更新材质参数；环境路径或 renderer 改变才重新生成 PMREM。环境 RenderTarget 以完整对象交给组件生命周期持有和释放，避免只释放纹理而遗留附件。
3. 首载编译检查同时观察贴图已就绪的最终材质，避免异步贴图变化后在用户进入时才同步编译。只在测量确认有收益、像素与交互回归通过时保留。
4. ego-lite 对照独立动画、真实绘制与帧回调等待；正常/压力各 60 s，捕捉秒级帧的主线程、GPU fence 和定时器。系统/浏览器调度证据不外推成 iPhone 真机结论。

## 验收与交付

- 相同交付条件双曲冷缓存至少三轮；单列模型/贴图开始、封面、完整画面、点击到播放，保留慢样本。
- 两曲固定背景与三角度像素对照；材质、分辨率和几何数一致。
- 原生手机快滑、反向、抬手/取消、缓动、持续旋转；键盘/滚轮/进度条、双向多轮、原生音频循环、暂停恢复、受控前后台、切曲和资源数量有界。
- 切曲复用纹理/环境对象，旋转按原约定重置；异常切曲保留原会话。
- runtime/deployment、类型、生产构建、本地交付及双公网 HTTP 全量校验；公网 ego-lite 后完成 commit/push。
- 不以低电量测试机的帧率保证真机帧率，不把无脚本长帧当作已修复的应用长任务。

## 验收发现的播放器生命周期问题

桌面回归中，按住暂停图标跨过一次进度更新后，按钮本身仍在，但图标和按下的 SVG 节点已被卸载，
浏览器因此没有发出 click。实测按住约 0.57 s：按钮相同、图标不同、按下节点已断开、音频仍播放。
原因是 `EnhancedAudioPlayer` 在每次渲染内部声明图标组件，进度更新会改变组件类型。

此修复属于已有“播放、暂停、全部手势”验收范围：只将图标组件定义移到模块级，
保留原 SVG、样式、颜色、播放器 props 与音频/seek 接口；缓冲图标通过内部 accent 参数取色。
验收增加原生鼠标按住期间进度仍更新、图标节点保持、松开后暂停，以及重新播放和双向拖动。
