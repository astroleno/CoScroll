这是原模块中的探测策略调整，不增加运行时模块或外部接口。

## 拟确认的改动

### 1. 无损压缩交付

扩展现有 package-release、release-lib、upload-cos-release、preview-release、verify-release；
只对可压缩静态资源使用 gzip，音频保持原字节与 Range，图片及字体不重复压缩。
URL、资源 MIME、缓存隔离和 CORS 保持既有约定；只新增不可变发布前缀，不改 CDN 全局规则或 Nginx 配置。

现有 manifest entry.bytes / sha256 继续描述包内及 COS 中的实际存储字节。
可选字段 contentEncoding='gzip'、decodedBytes、decodedSha256 描述解码后的原始内容。
包校验必须同时核对存储摘要与解压后摘要；旧 manifest 仍可读取。
上传时带 Content-Encoding，重复上传比较编码与摘要，拒绝覆盖冲突对象。
本地预览同样发送编码头，HTTP 校验同时验证原始传输与浏览器解码后的语义，保留音频 Range 检查。
ModelPreloader 当前 preparedSha256 始终校验浏览器已解码的完整原始 JSON，不放宽完整性要求。

### 2. 现有模型恢复与首屏脚本

ModelPreloader 的 OBJLoader / GLTFLoader 只在原模型回退或自定义格式实际需要时导入；
默认预计算路径不下载备用解析器。loadModel / getOffsetGeometry 与配置接口不变。
在 preparedModelGeometry 的现有解码中按有限工作量让出主线程，避免多段恢复串成一个长任务；
保留所有 Float32/Float64 位、索引、元数据、边界、内外层，以及损坏数据/不支持解压时的原文件回退。
不引入 Worker、新二进制模型格式、量化或几何简化。
