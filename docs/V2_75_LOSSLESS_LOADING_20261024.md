# 75 字无损加载与内存优化验收

2026-10-24，本地实现、完整生产构建及验收已通过。本报告随模型优化代码入库，未外部部署。
基准提交：`ac872e82eb04ce10632335b3f6e03c7146874116`。

## 实测结果

| 口径 | 原版 | 优化后 | 变化 |
| --- | ---: | ---: | ---: |
| 75 字实际发布载荷 | 125,848,046 B | 119,026,900 B | 减少 **5.42%** |
| 首页初始 JS 发布字节 | 361,024 B | 370,110 B | 增加 9,086 B，一次加载 |
| 75 份运行载荷本地文件 | 166,214,996 B | 119,026,900 B | 减少 28.39% |
| 同序列浏览时的模型缓冲平均驻留 | 27,917,156 B | 12,449,117 B | 减少 **55.41%** |
| 六字离线解码额外内存峰值观测均值 | 29,415,942 B | 18,217,109 B | 减少 **38.07%** |

计入增加的首页 JS 后，完整加载 75 字仍净省 **6,812,060 B（约 6.81 MB）**；
“首页初始 JS + 75 字载荷”合计减少 5.40%。这不是单次首屏或整站所有资源的降幅。
原先争取的 20% 网络降幅没有达到，未通过降低精度、简化笔画或改变玉石参数补足。

实际发布对照使用相同的 Node 26.7.0、zlib 1.2.12 和发布器 gzip9/90% 选择规则。
原 JSON 从基准提交读取，逐个核对改动前摘要；新字节逐个匹配本次发布清单。
原先固定的 Node 22 / zlib 1.3.1 对照为 125,145,861 → 119,026,900 B，减少 4.89%，
仍保留在生成报告和不可变基线中；两套压缩环境的结果分别记录，不混为同一测量。

首页代码成本来自两次实际生产编译的 `/layout` 与 `/page` 初始 JS 文件并集，
两次使用同一 Node、依赖、配置及发布标识，只恢复相关加载模块和注册表作旧版对照。
优化后五份 JS 的压缩字节和摘要与发布清单相符，成本包含新增解码、调度、所有权及注册表信息。

## 实现

- 75 字选择无损二进制载荷；26 个 OBJ 预处理 JSON 保留原文件、摘要和 generation。
  public 中每字只保留选定的运行载荷，101 个原始模型继续提供回退。
- 二进制按属性解压，恢复原 Float32/索引位模式；利用内外层关联存储可逆残差，避免大段 Base64 和大 JSON 解析。
  保留约 4 ms 的合作让帧，几何解码同时最多一个，当前请求可以提升预取任务的优先级。
- 两层校验完成后共同发布；切换期间继续显示旧字。当前目标、仍可见的上一字和下一字按实际引用保护。
  过期且无人引用的任务中止，迟到结果不会重新填充已清理缓存。
- 闲置缓存同时受最多 8 项和 8 MiB 限制，包含基础层、外层参数版本、索引及共享缓冲。
  淘汰和卸载按所有权释放，避免显示中的几何被释放或同一几何重复释放。
- 损坏、截断、摘要/版本/映射不符或缺少解压能力时，按原模型及完整原算法恢复。
  二进制内部压缩与 HTTP Content-Encoding 分开管理。

完整属性重复顶点审计结果为 **0**，因此没有进行重索引。单个活跃字的固有几何缓冲保持原样，
驻留减少来自缓存预算及生命周期；临时占用减少来自传输表示、解码副本和并发控制。

## 字形、玉石与生命周期验收

75 字的基础层及外层全部通过原始几何和逐三角形展开属性的逐位指纹检查，
覆盖坐标、法线、全部 UV、索引、组、drawRange、边界和几何元信息。
101 个源模型、26 个旧载荷，以及受保护的几何算法、材质补丁、纹理、HDR 等共 138 份输入摘要保持不变。

在实际原玉石双层场景、相同相机/灯光/DPR/贴图和固定角度下，
**75 字 × 16 视角，共 1,200 次比较的像素差为 0**，旧版自对照噪声同为 0。
妙、化、安、净、泰、雾完成整圈旋转，材质、法线贴图、环境图及着色程序保持稳定。

本次未加调试变量的实际生产发布包另通过：

- 15 个经文时间锚点，模型、经文和音频位置对应。
- 连续 27 次快速跳转，89 个观测帧中没有闪空、半套模型、显示中几何已被释放或重复释放。
- 两次真实鼠标播放/暂停操作，以及四次经文切换；完整 196 个观测帧无上述所有权异常、无运行错误。
  HDR、法线贴图和材质在切经时复用，旋转按原行为重置。
- 独立 JadeV6 页三次模型切换和外层偏移调整；基础层复用，旧本地外层只释放一次。
  经 AppRouter 同文档卸载后，本地外层释放一次，共享基础层没有被页面误释放。

## 测量范围

驻留测量使用全部 75 字的相同顺序，保护当前和下一字，比较原 8 项闲置 LRU 与真实新缓存。
去除前 10 字冷启动段后统计 65 步平均值。最大闲置缓冲为 **8,381,080 B**，低于 8 MiB；
解除全部所有权并清空后驻留为 0。统计按实际 ArrayBuffer 身份和总 byteLength 计量，
不包含纹理、渲染目标、整机内存或 GPU 驱动物理内存。

离线解码测量使用 Node 22，每字/格式/轮次独立子进程，三轮交替，
每 1 ms 观察 heapUsed + arrayBuffers 增长，并扣除相同的最终几何输出，不强制 GC。
短暂同步峰值可能被采样遗漏，因此 38.07% 是该条件下的额外内存峰值观测结果。

同一桌面 Chromium 154，六字各预热三次、交替采样五次，解码中位数如下：

| 字 | JSON v1 | binary v2 |
| --- | ---: | ---: |
| 妙 | 86.9 ms | 74.8 ms |
| 化 | 44.5 ms | 39.1 ms |
| 安 | 43.7 ms | 50.1 ms |
| 净 | 40.3 ms | 38.4 ms |
| 泰 | 43.9 ms | 40.1 ms |
| 雾 | 33.3 ms | 32.5 ms |

单字时间存在波动，安在本轮样本中变慢；不承诺每个字都更快。
本轮没有真实手机 FPS、整机内存或统一主线程长任务收益结论。
