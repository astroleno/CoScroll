## 概念一致性与心流判断

两份审阅都将 CoScroll 理解为“由声音展开、可以往返的数字经卷”：声音提供时间，竖排文字提供阅读路径，玉字提供视觉锚点，丝绸维持连续空间。当前手写开场、玉质正文和曲目配色之间存在连贯的材质与情绪关系；默认操作只占据边缘，适合继续保持克制。

已经成立的体验包括：用户主动进入才发声；选曲面板覆盖当前作品而无需离开页面；暂停时换曲保持暂停、从曲首开始；Escape 关闭后焦点回到入口；拖动正文可以在暂停时定位。这些行为有助于持续观看，也让用户能随时接管。

心流的主要风险来自三处：短屏直接切掉内容，让用户寻找缺失的字；微小操作区域要求精细瞄准；系统请求安静后场景仍自主运动。它们有观察或源码依据。至于首次访客是否知道整屏可点、普通暂停时是否应冻结全部装饰，本轮没有用户研究支持，应保留为待验证假设，不因此恢复旧提醒语。

应继续保持专属短序、纯净开场、两首曲目的既有色系、丝绸、完整玉字、前后竖排深度关系、两画布和双向无限滚动。上下视口硬裁切与有意的玉字遮挡、左右边缘渐隐需要分别判断。

## 建议的迭代范围与验收

建议先完成短屏规则与操作区域的一轮小范围设计确认，把二者一起评估，避免增大按钮后反而进一步压缩正文。实现验收应同时覆盖两首：390×844 竖屏、844×390 横屏、矮桌面窗口及原桌面基线；取当前句、代表性长句和多个玉字姿态，核对完整性、原有比例和层次。旋转屏幕不应重置播放位置或暂停状态。

随后接入减少动态效果，并统一曲目类型副信息。减少模式需覆盖进入前已开启与运行中切换两种情况，验证静止状态、播放同步、拖动、换曲和循环；普通偏好下保留已确认的动效。曲目范围说明放在做选择的面板中，中央开场继续只显示短序。

语义正文可作为独立且有边界的补齐项，先确定辅助技术如何进入和阅读、视觉用户是否需要按需入口。复用现有歌词，不另维护一份经文；真实读屏验证与仿真布局验证分别记录。

当前证据支持局部迭代，没有支持新增导航体系、通用状态框架、模型浏览目录或整体视觉改版的需求。以上是评审建议，尚未执行产品修改，也不是已批准的实施方案。
