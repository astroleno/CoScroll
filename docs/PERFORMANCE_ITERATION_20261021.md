# CoScroll 性能迭代（2026-10-21）

## 已确认范围

用户于本轮确认：保留两层画布、丝绸 shader、玉质双层材质、完整字库与全部手势，
优化加载顺序、封面期间的隐藏场景渲染和歌词的逐帧更新。沿用 `decoupled` 分支；
实现、验证后 commit 并 push。本轮不包含新的公网发布。

## 模块与接口

- `RootLayout` 提前声明完整字体；首页的服务端加载画面预载字体和默认项目 JSON，
  继续通过 `assetUrl` 解析交付地址。整套字体使用低优先级，配置使用高优先级，
  防止字体争抢启动脚本带宽。其他实验页不强制预载这两项资源。
- `HomePage` 通过内部时间引用传递连续视觉时间；音频时间、播放意图、seek、循环与项目配置接口兼容。
- `UnifiedLyricsAndModel` 增加默认启用的内部 `active` 参数；主页面封面期间暂停正文渲染。
- 分层歌词的布局计算与 React Hook 分离；渲染循环更新对象位置、透明度、颜色和羽化。
  React 仅在歌词窗口、文字或字体等结构内容变化时更新。
- 两层画布的分辨率、模型几何、光照、材质、排版算法和手势映射保持现有参数。

回归中发现旧进度条会在没有进行鼠标拖动的离开事件上提交过期位置；原来的延迟 seek
也可能覆盖已经立即应用的新位置。本轮同时修复：进度拖动统一使用 Pointer Events 和最新时间引用，
结束事件仅提交实际拖动；新的即时 seek 取消旧队列，定时器在递归调度前先清空自身。
音频组件的公开 props、循环规则、播放意图与失败重试接口不变。

## 验收

1. 生产构建、类型检查、部署防护与运行时回归通过。
2. ego-lite 使用同一份脚本比较基线与候选：390×844、DPR 2、禁用浏览器缓存，记录环境和全部样本。
3. 封面期间正文不再持续绘制；播放期间 R3F 的 React 提交不再随每一动画帧发生。
4. 字体与配置从 HTML 预载启动；正常浏览器缓存策略下不重复下载，无 404 或跨域错误；
   完整字库文件保持相同 SHA-256。禁用缓存时的额外请求独立记录。
5. 开场、正文的桌面与竖屏截图人工检查；播放、暂停、双向横滑、循环回退、进度拖动与续播通过。
6. 帧率使用同环境前后对照，如实记录波动；不将电脑上的视口模拟作为手机真机结果。

帧内对象更新参考 [React Three Fiber 的性能建议](https://r3f.docs.pmnd.rs/advanced/pitfalls)，
保持 React 负责结构变化、Three 渲染循环负责连续动画。`test/runtime/lyric-motion.test.mjs`
覆盖分层、循环、负数预览、边缘变化、时间引用与 seek 重置；
`ego-performance.mjs`、`ego-interactions.mjs` 供已拥有的 ego-lite Page 调用，不启动独立浏览器。

候选第一次访问全新 release URL 时保留正常浏览器缓存策略：音频、字体均就绪 1.92 秒，
背景首次绘制 2.93 秒，正文 27.37 FPS，R3F 提交 44 次；该次字体与配置各只有一个真实 HTTP 请求。

焦点为模拟状态；基线压力样本的帧率甚至高于正常样本，说明单次采样受环境影响。
计数与代码能确认工作量减少，帧率没有达到稳定 60 FPS；以上结果不能代表手机真机性能，
也不是优化后的公网延迟测试。

### 功能与交付

- TypeScript、生产构建通过；运行时回归 12/12，部署防护 8/8。
- 本地交付验证覆盖全部 185 个文件、3 个音频 Range，哈希、MIME、缓存和跨域检查通过。
- 390×844、360×800：播放、暂停，两向 180 px 横滑各改变 15 秒，完整收到 pointerup，
  从 0 秒回退到 359.256327 秒、续播、进度条拖动与快速往返均通过，无横向溢出。
- 1440×900：Enter 开始/暂停、Home、方向键、Shift+方向键、鼠标拖动、滚轮及续播通过。
  工具发送的 180 单位滚轮输入实际产生 deltaY=360 的 DOM 事件；依据实际事件，
  187→157 秒符合原有 12 px/s 映射，最初固定预期 172 秒的测试判定已纠正。
- 约 20–25 ms 间隔连续输入 2、9、3、8、4、7 秒，只实际应用 2、4、7 三次 seek；
  队列结束后音频和进度条均为 7 秒。非拖动时鼠标移出进度条不再恢复旧位置。
- 开场与正文仍共用同一背景 Canvas，总数为 2；桌面、390 px 与 360 px 截图已人工核对。
  正常访问未捕获运行错误；保留基线已有的 Three 纹理警告和其他旧页面的构建 Hook 警告。

整套字体以默认优先级预载的中间候选曾延迟封面；最终改为低优先级后，压力条件下的
封面与音频就绪时间恢复，同时保留提前加载字体的效果。字体 SSR 转义、跨轮采样器遗漏和
工具默认导航等待超时均在最终验证前处理；失败/中间记录保留，不计作最终通过样本。

原始 JSON、请求日志、每轮脚本和截图保存在工作区 `.cache/optimization-20261021/`。
最终结果为 `final-performance.json`、`final-interactions.json`、`final-desktop.json` 和
`final-rapid-seeks.json`；中间候选结果分别保留。测试空间和临时预览服务已关闭。
本轮未上传 COS、未修改 CDN/Nginx、未切换公网版本。
