# 音频恢复与区域渲染回归迭代

状态：本地实现和软件验证完成。用户已同意按上一轮建议迭代；本轮音频与测试改动尚未提交、推送或发布。

## 工程复杂度判断

已确认的两处音频问题和自动像素门槛缺失值得修复。沿用现有组件、原生媒体事件、会话版本与测试辅助程序，
不引入全局状态机、播放器框架、额外服务或新的生产依赖。原始 review 中被反证的条目不转成修复任务。

## 模块与接口

- `AudioEngine` 增加一个加载状态通知（loading / ready / buffering / error）与显式重试版本。
  状态只在发生变化时通知；以实际 waiting / playing / canplay 事件表达缓冲，取消“余量不足两秒即卡顿”的猜测。
  保留启动阶段最多两次自动重试；最终失败通知界面并停止播放。手动重试重新加载，恢复最后的绝对位置，等待用户播放。
  重试、延迟回调和媒体事件沿用会话/请求版本隔离，暂停必须撤销待启动的播放意图。
- `ReadingSession` 接收状态并派生 ready / buffering，保留播放意图和有符号循环时间轴的现有职责。
  错误不重置经文或位置；切经重置错误与自动重试次数，手动重试序号保持递增，避免切经复位被解释成新的重试。
  保留本目录已有的模型所有权修改。
- `EnhancedAudioPlayer` 在现有布局显示明确错误与“重试”按钮；加载/缓冲提供状态提示。
  缓冲时可暂停及拖动；最终失败时保留错误恢复入口，读屏能获知状态，键盘能触达按钮。
- `transmission-region-browser.mjs` 沿用真实双层玉石场景，支持 json-v1 / binary-v2，比较完整更新与区域更新，
  对非零像素差、GL 错误和未进入区域路径明确失败；初始化和失效时的完整更新仍合法。
- 增加一个现有 ego-browser 可执行的浏览器回归入口，不增加生产调试 API 或浏览器依赖。

## 验收

1. 启动失败自动重试有上限，耗尽后有用户可见错误和可用重试入口。
2. 重试保留当前位置与循环；重试期间最新 seek 优先。失败、取消或切经后迟到事件不得启动旧录音。
3. waiting 显示缓冲，playing / canplay 清理缓冲；暂停后网络恢复不得自行播放，缓冲期间能调整位置。
4. 解码错误、网络失败、恢复、快速切经及暂停/重试用真实组件行为验证；真实浏览器复核可见交互。
5. 两种布局、现有全部模型的完整/区域渲染逐像素差为零、GL 无错误、区域路径实际执行；结果可用单一命令重复。
6. 对当前模型无损加载改动运行相关数值、缓存和生命周期检查。该改动仍按其独立方案验收；
   本轮不修改其编码、解码或缓存设计，也不把未取得的真机数据写成已完成。
7. 完成本地构建/必要检查，保存简明结果；截图、构建副本和临时脚本清理。

## 已实施的行为

- 启动阶段最多两次自动重新加载；重复错误事件不重复排队，最终失败以界面提示与可用的“重试”按钮结束。
- 手动重试重新加载并恢复最后的绝对时间，含负循环；用户在恢复期间发出的新定位优先。恢复后保持暂停，用户点播放继续。
- 已经可播放的录音中途失败时，不自动从头重新加载；保留位置并提供同一个恢复入口。
- waiting / stalled（且数据不足）显示缓冲；playing / canplay 或用户暂停清理提示。
  缓冲提示使用播放器上方的现有留白，正常播放时保持原有画面尺寸；失败时展开错误区域。
- 缓冲时保留暂停和定位；跨录音的旧事件、重试计时器与迟到 play promise 均受现有版本保护。
- 播放器以一个加载状态派生 ready / buffering，状态通知去重；没有增加生产依赖或全局状态库。

## 可重复的检查入口

```sh
npm run test:runtime
npm run test:deployment
npm run build
npm run test:visual -- --url http://127.0.0.1:3248/ --output /absolute/path/result.json
```

最后一条要求指定地址已有可访问的本地 CoScroll 构建、模型资源位于其应用基础路径下，且本机可用 ego-browser；
默认覆盖注册表全部 101 个模型、两种布局。跨来源发布包的 HTTP、MIME、缓存和 CORS 仍由已有发布工具验证。
`--limit` 仅用于明确缩小范围的冒烟检查，结果会注明是否覆盖完整注册表。
默认新建的测试空间在成功后关闭；主线程已有空间可传 `--space <id>` 复用，由调用方在全部检查后统一结束。

像素差非零、GL 错误、未实际进入区域路径或渲染状态泄漏均返回非零退出码。
初始化等必要的完整更新允许存在；此入口是独立浏览器门槛，普通 Node 测试不启动浏览器。本项目没有在本轮新增 CI 配置。
