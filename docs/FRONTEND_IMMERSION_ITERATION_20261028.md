# 前端沉浸体验迭代设计与验收

日期：2026-10-28。依据[独立审阅汇总](reviews/2026-10-28-frontend/README.md)，用户已授权开始迭代、commit/push 并更新腾讯公网。复用当前 `decoupled` 工作区，由主线程实施；此前的子 agent 授权用于独立 review，本轮不扩派实现任务。

## 目标与设计边界

交付 R-01 至 R-05：矮屏内容完整、核心触摸容错、系统减少动态效果、录音形式信息与正文语义。沿用丝绸、完整玉字、前后竖排、正交投影、双画布、曲目配色、无限滚动和手写短序，不改录音、歌词、模型来源或几何精度，不增加默认可见的设置/导航面板。

用户对本轮局部迭代的授权用于落定以下具体行为。正常高度的既有场景参数和普通动效保留；空间不足时对整个前景统一取景，玉字与经文的相对比例和深度关系保持。正文语义采用同源歌词的辅助技术文本，默认画面不添加新入口或覆盖层。

## 模块与接口

| 模块 | 本轮实现 |
| --- | --- |
| `ClassicExperience`、`useReducedMotion` | 在正式入口集中订阅系统媒体查询，支持首次进入及运行中变更，将偏好传给背景与阅读会话；清理监听，不写用户持久设置。 |
| `SilkR3F` | 增加可选 `reducedMotion`，减少模式冻结已有 shader 时间，继续呈现同一材质；恢复偏好后从原时刻继续。 |
| `UnifiedLyricsAndModel`、场景取景计算 | 依据 Canvas 实际可用高度计算正交 zoom，只在原取景不足时缩小整个场景；原有正交类型、各对象比例、轨道和深度保持。保守计入最长歌词列与玉字完整边界。尺寸变化不重建 Canvas/音频，不逐帧测量 DOM。 |
| `ReadingSession` | 高度使用动态视口；短屏压缩 footer 空白并给标题留出安全空间。减少模式停止玉字自主旋转；歌词播放按真实媒体时间对应的整句更新，用户直接拖动仍实时定位，暂停不产生漂移。 |
| `EnhancedAudioPlayer`、`ClassicControls` | 播放、曲名和进度 input 的有效触摸高度至少 44px；32px 图标、6px 细轨道仍保留。保持原生 range 键盘语义、pointer capture 和焦点反馈，限制 hover 反馈到合适指针，进度不增加跟随动画。 |
| `catalog`、选曲副信息 | 《妙法》明确为“摘编歌曲”，保留赞诗与原专辑来源；《心经》保持歌曲版。中央开场不增加信息。 |
| 正文辅助阅读 | 从会话已验证的 `lyrics` 输出有标题的非 live 语义文本，保持原顺序和重复歌词，跳过纯空白占位；换曲替换文本，开场阶段不暴露未进入的正文，不自动逐句朗读。 |

取景与减少模式的时间选择采用可单独验证的纯计算；保持一套真实媒体时间和一份歌词，不引入新状态框架或动画依赖。取景不会跟随当前句/当前锚字不断缩放。

## 验收

1. 两首曲目覆盖桌面、390×844 手机仿真、844×390 横屏和矮桌面：当前句及最长句首末可见，玉字多姿态完整；区分有意前后遮挡与上下硬裁切。旋转后位置和播放意图保持，Canvas 仍为两个。
2. 热区边缘可点击/拖动，轨道上下偏移仍能开始定位；键盘 Home/End、方向键、Enter/Space、焦点归还和指针取消正常，不误触正文。
3. 系统减少动态效果在进入前与运行中均生效：无输入且暂停时丝绸/模型静止；播放歌词按当前录音句子更新，拖动/换曲/自然循环正常；普通偏好恢复原动效。
4. 辅助树含同一曲目的完整有序歌词，无自动 live 播报、无前一曲残留；面板明确录音形式。实际读屏软件/真机若未测试须如实记录。
5. `tracks:check`、`models:check`、发布与运行回归、类型检查、生产构建和包验证通过。正常尺寸的画质、材质及几何保持，不把缩小渲染精度作为适配。
6. 产品及审阅资料先 commit/push，从该提交的干净源码打正式候选；上传 COS 并完整校验后暂存腾讯，仅切换 CoScroll 当前链接，保存回滚依据。两站 CoScroll/coscroll 两首浏览器与 HTTP 回归通过后归档验证记录并再 commit/push。
7. CDN 下载保持现有限速：四路每路最高 150 KiB/s，与浏览器大文件下载错开。测试截图、页面、临时包/脚本/日志/构建副本清理；原有 13 份资料保留。

## 本地实现与验证

五项改动已实现。类型检查、两首专属开场检查、101 模型完整性检查、发布防护 16/16、运行回归 119/119 通过。新增回归覆盖短屏取景、原有高屏相机参数、已接入源模型的高度边界、语义歌词顺序/重复段以及减少动态效果的跨循环句子选择。

真实本地浏览器完成两首手机/横屏、矮桌面、最长句和《心经》330 秒圆字检查：横屏正文 314px、footer 76px；原竖屏正文 716px、footer 128px。播放/暂停与进度 input 实测均为 44px 高，并从新增透明区域完成触摸操作。减少模式静止 30 帧、播放时整句更新、Escape 焦点归还、辅助树歌词标题与内容通过；没有宣称真机或真实读屏软件验收。

完整运行回归首次在测试阈值修订前启动，记录为 118/119；修订后定向检查通过，再完整重跑为 119/119，零跳过。最初阈值将旧 262px 正文高度也要求 16px 字符；最终明确新横屏 314px 至少 16px，旧 262px 极短区域至少 14px，均要求完整呈现。取景边距的 0.14px 差异也已修正并回归。没有跳过失败项。
